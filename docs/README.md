# PyTricks Archive — Documentation

A personal archive of the PyTricks newsletter snippets, kept as standalone Python files so
they can be run and re-read rather than lost in an inbox.

```
PyTricks-Archive/
├── docs/
│   ├── README.md          this page
│   ├── tricks.md          the full index
│   ├── usage.md           running and finding them
│   ├── architecture.md    naming, branches, the website
│   ├── faq.md             provenance, coverage, licensing
│   ├── roadmap.md         gaps and non-goals
│   └── legal/             privacy policy and terms
└── PyTricks/              31 standalone .py files
```

## Pages

- [Index](./tricks.md) — every trick, by original subject line
- [Usage](./usage.md) — running them, and finding the one you want
- [Architecture](./architecture.md) — the naming scheme, the two branches, the website
- [FAQ](./faq.md) — where these came from, what is covered, what you may do with them
- [Roadmap](./roadmap.md) — gaps and non-goals

## Provenance matters here

The tricks are **Dan Bader's work**, published through the PyTricks newsletter at
[Real Python](https://realpython.com/). This repository is one reader's archive of snippets
they found useful. It did not author them and holds no rights in them.

If they are useful to you, the right response is to subscribe to the newsletter rather than
to treat this repository as the source. See
[`internal/known-issues.md`](./internal/known-issues.md) for the licensing question that
follows from this.

## What makes it useful

An inbox is a bad place to keep code you want to run again. Every trick here is a file you can
execute, grep, and link to — which is the whole reason the archive exists.
