## Key Features

- 31 tricks, each a standalone `.py` file you can run directly.
- Indexed by the original newsletter subject line, so you can find the one you half-remember.
- Filenames describe the topic, so the folder is browsable without the index.
- Also published as a website, with a link straight to each trick.
- No dependencies — every file is standard-library Python.

## Usage

Browse the [index](docs/tricks.md), or run any file directly:

```bash
python PyTricks/listcomprehensions.py
```

See [`docs/usage.md`](docs/usage.md).
